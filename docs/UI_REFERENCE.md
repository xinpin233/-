# 纸面胶卷界面

正式主场景已采用用户提供的米白、红黑胶卷参考：大号 REEL 标题、硬边阴影、上下齿孔、分镜指示、秒刻度、波形与文字素材块、红色放映按钮。没有配色选择器。

当前主场景沿用电话亭序幕的三段素材和动画接入；“门后”四段素材关卡仍可运行。标题、秒刻度和左侧分镜数量随实际数据变化。放映、暂停、停止、复位和静音仍由游戏控制器管理。

素材排序通过鼠标直接拖动：保持抓取位置，抬起时变红并轻微倾斜，邻居平滑让位，松手吸附到空槽。Esc 或拖出轨道可取消；播放开始、窗口失焦及窗口缩放会清理拖动状态。

界面基准为 1424 × 900，窗口默认 1280 × 810；窗口使用等比例缩放及布局扩展。美术素材的长宽比与界面布局分开处理。电话亭原图为 1600 × 1200，分镜场景画布为 1100 × 825，保持 4:3 并完整居中放进宽屏胶卷框，剩余区域留暗边。切镜也限制在同一个画面开口内。没有横向或纵向单独拉伸。

自定义分镜根节点可设置 Vector2 类型的 canvas_size 元数据，声明原生画布尺寸，默认 1100 × 825。原生旧分镜仍使用 1100 × 375。真实视频同样等比例居中。

验证：
- tests/smoke_test.gd：门后四段关卡、试听、拖拽提交和成功/失败路线。
- tests/paper_ui_test.gd：电话亭三段、真实鼠标拖起/让位/释放、取消、播放锁定、素材比例及三个窗口尺寸。
- tests/drag_demo.gd：生成真实拖动录制帧，输出 artifacts/drag_motion/frames/。
- 使用 Godot 执行 --script res://tests/paper_ui_test.gd -- --capture 可生成 artifacts/paper_ui.png 和 paper_drag.png；无头测试不进行截图。

UI 参考历史绘图工具 tools/render_ui_reference.py 继续保留，正式界面以 Godot 场景为准。
