# 复古终端界面参考 · 01

本轮提供一张独立的 1920 × 1080 界面风格稿：`artifacts/ui_reference/retro_console_v1.png`。这是按参考方向绘制的效果图，尚未替换主场景和游戏主题。

- 深橄榄黑机箱、米白塑料边框和实体按键，对应用户提供的终端设备风格。
- 绿色 CRT 扫描线处理的放映区；图中影像来自本项目现有演示场景，不代表新的视频素材。
- 右侧卷带机显示等待状态与播放控制；下方音频区保留波形、素材标题、描述文字和时长。
- 时间线素材块仍以直接拖拽为主要排序方式，实体按钮用于播放、复位和声音开关。

重绘命令：`python tools/render_ui_reference.py`。需要 Pillow 和 Windows 字体。该工具仅绘制预览图片，不修改正式游戏 UI。

拖拽动画已在正式场景实现，可查看 `artifacts/drag_motion/drag_preview.gif` 或 `.mp4`。录制操作见 README。
