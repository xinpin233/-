# 声之行 · 声音剪辑台

一个可直接运行的 Godot 音频排序叙事解谜原型。界面采用米白底、红黑胶卷框和可直接拖拽的波形素材块，没有配色切换。主场景使用电话亭动画序幕；门后四段声音关卡作为独立机制样例保留。

## 打开与操作

使用 **Godot 4.4 或更新的 Godot 4** 导入本目录的 `project.godot`，按 **F5** 运行。开发验证使用本机 Godot 4.7.2。

- 点击音频素材听单段音效；波形来自实际 WAV 素材。电话亭包含投币、拨号、电话反馈三段素材；门后样例包含滴答、惊叫、敲门、警铃四段素材。
- 抓住素材块任意位置拖动，整块波形和文字一起抬起，并保持抓取位置跟手。拖过相邻位置时，其他素材会平滑让位，空槽和红色边线提示落点；松手后素材吸附落位。排序直接通过拖拽完成。
- 拖动中按 Esc，或拖出轨道较远后松手，素材会返回原位。窗口失去焦点、开始播放或重置时会清理拖动状态。
- 点击「按此顺序放映」，或者按空格；再次按空格暂停 / 继续。
- 放映及暂停期间锁定排序与试听，避免改动正在播放的音轨。
- Esc 停止并保留排序；R 恢复初始顺序；M 静音；Tab 切换按钮焦点，Enter 执行。
- 结局后可以直接重播，也可以重排后再试。

## 已接通的玩法

主场景为电话亭序幕，正确顺序是投币 → 拨号 → 电话反馈。继续保留原有自动开场和结尾场景接入。电话亭原图为 4:3，等比例居中放进宽屏胶卷框，余下区域留边；界面布局独立于素材比例。

独立的「门后」样例：

- **惊叫 → 滴答 → 敲门 → 警铃**：主角判断门外有人需要帮助，按正确顺序回撤求助，在 **12 秒**处平安离开。
- 其他顺序会进入错误分支，在本关的 **12 秒**结尾被卷闸封住，放映停止。

门后样例保留参考故事的“被困”失败结局，尚未制作主角死亡镜头。门后样例使用原生绘制的动态分镜，电话亭使用已接入的美术场景。已预留成功 / 失败 `.ogv` 视频接入口，但没有虚构视频素材。音效沿用参考文件夹里的合成示例。

## 目录与职责

```text
project.godot                  Godot 项目入口
scenes/main.tscn               主界面布局，可在编辑器中查看和调整
scripts/
  core/                       状态与场景组装、信号连接
  data/                       音频及关卡资源结构、基础校验
  gameplay/                   纯排序与通关规则
  systems/                    播放时钟、独立音频播放器
  presentation/               胶卷分镜、剧情字幕、可替换视频显示
  ui/                         音频条、波形、时间线、主题
resources/
  clips/                      每条声音的名称、音频引用、颜色与波形
  levels/                     初始排序、正确排序、时长、结局及视频路径
assets/audio/                 可播放 WAV 素材
assets/video/                 正式视频预留目录与接入说明
tools/                        示例声音、波形资源生成工具
tests/                        可重复运行的集成检查
docs/                         模块说明、扩展与素材规范
```

新增音效无需修改播放器；新增关卡可复制 `.tres` 并调整数据。具体剧情画面与字幕仍是「门后」的四段分镜，实现新故事时需要一起替换表现层。详见 `docs/ARCHITECTURE.md`。

## 验证

Godot 编辑器首次导入完成后，在项目目录执行（`godot` 替换成本机 Godot 程序路径）：

```powershell
godot --headless --path . --script res://tests/smoke_test.gd
godot --headless --path . --script res://tests/paper_ui_test.gd
```

检查电话亭和门后两组素材、真实鼠标拖动、抬起倾斜、邻居让位、松手落位、拖出及 Esc 取消、播放锁定、暂停、成功/失败分支与停止/重置。另在 1000×700、1424×900、1920×1080 检查素材完整可见、长宽等比例及界面边界。

需要截图时移除 `--headless`，并添加 `-- --capture`，截图写入 `artifacts/`。

录制可重复的拖拽动画：`godot --path . --fixed-fps 60 --script res://tests/drag_demo.gd`。该脚本模拟实际鼠标操作，以 30 fps 保存渲染帧到 `artifacts/drag_motion/frames/`，供合成预览视频；不会修改关卡配置。

修改 WAV 后运行 `python tools/build_waveforms.py` 更新波形；重建示例声音使用 `python tools/generate_reference_audio.py`，然后重新生成波形。Python 仅用于素材工具，运行游戏不需要 Python。
